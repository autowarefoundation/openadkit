# Support

## Versioning & support policy

Open AD Kit follows [Semantic Versioning](https://semver.org/), and each release
pins a specific upstream Autoware meta-release. For the full policy — version
scheme, Autoware mapping, ROS 2 distro support, and what "supported" means — see
the **[Versioning & Support Policy](https://autowarefoundation.github.io/openadkit/getting-started/versioning/)**.

## Getting help

- **Questions and bug reports:** [GitHub Issues](https://github.com/autowarefoundation/openadkit/issues)
- **Documentation:** <https://autowarefoundation.github.io/openadkit/>
- **Troubleshooting:** [Getting Started → Troubleshooting](https://autowarefoundation.github.io/openadkit/getting-started/troubleshooting/)

## Security

To report a security vulnerability, please use [GitHub's private security advisory reporting](https://github.com/autowarefoundation/openadkit/security/advisories/new) rather than a public issue.
