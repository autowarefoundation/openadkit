!!! tip "Release bundles"
    Each stable GitHub Release publishes a versionless `openadkit` installer and
    one `openadkit-vX.Y.Z.tar.gz` containing the runtime entry point and the
    curated deployments (planning, logging, scenario, and CARLA). Zenoh stays a
    source-checkout workflow. Images and sample data are pulled on demand. Until
    the first release exists, use a source checkout.
