!!! tip "Prefer a release bundle?"
    Once a release is published, you can download a self-contained `.tar.gz` instead of cloning:
    `curl -fL https://github.com/autowarefoundation/openadkit/releases/latest/download/planning-simulation.tar.gz | tar xz`
    Bundles include `install.sh` and a merged env file so every command runs from the extracted directory. See each [deployment page](../deployment/index.md) for details.
