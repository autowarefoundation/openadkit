# Releases

[GitHub Releases](https://github.com/autowarefoundation/openadkit/releases) is the
canonical source for published versions, release notes, the unified runtime
bundle, and provenance metadata. Each stable release publishes a versionless
`openadkit` installer and the versioned `openadkit-vX.Y.Z.tar.gz` bundle; see
[Getting Started](../getting-started/index.md) for both install paths. Installed
releases move to the latest stable version with `openadkit upgrade`. Image
naming and versioning are documented in
[Container Images & Versioning](../getting-started/container-images.md).
